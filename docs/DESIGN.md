# 设计与动效清单

## 视觉与可访问性令牌

| 令牌 | 浅色 / 深色 | 用途 | 约束 |
| --- | --- | --- | --- |
| `FOCUS_RING` | `#1c1917` / `#fafafa` | 所有 `focus_visible` 的 2pt 焦点环（`ui::focus_ring`） | 对各自底色 ≥ 3:1；**不要**再用 `theme().ring`（浅色只有 2.59:1） |
| `FIELD_BORDER` | `#929292` / `#666666` | 输入框边界 | 对各自底色 3.1:1；焦点态由 `FOCUS_RING` 负责，边框本身不做「假焦点」 |

- 输入类控件统一走 `ui::text_field`：高 24、内距 8、圆角 6、边界 `FIELD_BORDER`、焦点环 `focus_ring`；`time_field` 用同一组值，步进按钮同为 24×24。
- 提醒行右侧是固定车道：次数 54 宽（等宽数字、右对齐），打卡与「⋯」都是 24×24 的方格；周期徽标留在标题行，靠行内 8pt 间隙与右侧分开，长名字不再挤走右侧动作。
- 打卡按钮只有「已到期」的行用 `ActionTone::Accent`，其余行 `Quiet`：一张卡片只留一个金黄焦点。
- 胶囊组（快捷填入、常用时刻）在放不下时折行（`ui::choice_group_wrap`），不允许被卡片边缘裁掉。

### 尺度

所有尺度都在 `src/ui/tokens.rs`，组件只取值，页面只给布局。

| 令牌 | 档位 | 用在哪 |
| --- | --- | --- |
| `font` | `CAPTION 10.5` / `LABEL 11` / `BODY 12` / `TITLE 13` | 角标与键帽 / 标签与说明 / 正文与数值 / 标题 |
| `radius` | `SM 3` / `MD 4` / `LG 6` / `XL 8` / `MAX 12` | 微控件 / 菜单项与徽章 / 按钮、输入框、分段 / 抽屉与 Toast / 窗口卡片 |
| `space` | `HAIR 2` / `TIGHT 4` / `SNUG 6` / `GAP 8` / `GROUP 12` / `INSET 14` / `SECTION 16` | 图标修正 / 控件内部 / 相邻控件与列表行 / 一组内容与抽屉内缩 / 区块 / 卡片内缩 / 大区块 |
| `size` | `CONTROL_SM 20` / `CONTROL_MD 24` | 紧凑按钮 / 图标按钮、动作按钮、输入框 |
| `motion` | `FAST 120` / `BASE 240` | 悬浮、高亮与状态色 / 移到新位置、退场 |

顶栏的五个操作都是 `IconTone::Ghost`：没有底和描边，只有「抽屉正开着」才浮出金黄。提醒数量只在底栏出现一次。

## 动效清单

界面上的每一次状态变化都在这张表里；写代码之前先写它，改完再逐条在运行的应用里看一遍
（对应 NSH 设计指南的「Motion inventory」）。`reduce_motion()` 打开时所有时长归零，只留终态。

### 主卡片（列表 / 抽屉 / 撤销条）

| 变化 | 工具 | 令牌 | 减弱动态效果 |
| --- | --- | --- | --- |
| 图标按钮、动作按钮、文字按钮、步进按钮、行内胶囊、分段切换、图标块、预设卡、折叠行、菜单触发器的悬浮 / 按压 | `transition_colors` + `transition_transform`（按压 scale 0.92–0.98） | `motion::FAST` | 时长归零，直接到终态 |
| 菜单项的悬浮 / 按压 | `transition_colors` | `motion::FAST` | 归零 |
| 打卡 | `motion().play(MotionPreset::Pulse)`：scale 1 → 1.06 → 1 | 预设 500ms ease-in-out | `play` 直接落到终态 |
| 新建一行 / 删除一行 / 撤销删除 | `LayoutAnimation`（行的位置、出现、消失） | `motion::BASE` ease-in-out | `ui::animate_rows()` 不调用，直接换位 |
| 撤销条进入 | toast 的 `starting_class`：淡入 + 上移 12 | `motion::BASE` | 时长归零 |
| 撤销条退场 | toast 的 `ending_class`：淡出 + 上移 8 + 缩到 0.95；内容在树上多留 `TOAST_EXIT_MS` | `motion::BASE` | 时长归零 |
| 撤销条倒计时 | `scale_x` + `transition_transform`（每秒推进，只动合成层） | `motion::BASE` | 归零 |
| 抽屉展开 / 收起 | `collapsible(reveal)` 的 spring | 库默认 | 库内按 `reduce_motion` 跳过 |
| 开关 | `transition_colors` / `transition_transform` | `motion::FAST` | 归零 |
| 状态徽章换语气 | `transition_colors` | `motion::FAST` | 归零 |

### 应用更新（设置抽屉第 5 区块）

| 变化 | 工具 | 令牌 | 为什么 |
| --- | --- | --- | --- |
| 状态徽章换语气：检查中 → 已是最新 / 有新版本 → 待更新 / 更新中 | `transition_colors` | `motion::FAST` 120ms | 只有颜色渐变，文字立即替换：两段文字交叉淡入会重叠成乱码 |
| 下载进度条前进 | 宽度 + `transition_all` | 200ms | 宽度是轨道的 `relative` 百分比，窗口变宽、缩放变了也照样满格；不知道总大小时不推进 |
| 进度条出现 / 收起 | 无（即时） | — | 它是功能数据；高度动画会把下面的说明文字推来推去 |
| 动作按钮切换：检查更新 / 下载更新 / 打开下载页 / 重启并更新 | 无（即时） | — | 四个动作互斥、位置固定；淡入淡出会让光标下的目标抖动 |
| 更新说明摘要出现 | 无（即时） | — | 只在「有新版本」时出现一次，不反复触发 |
| 按钮按压 | `active` | scale 0.97 + opacity | 沿用 `ui::text_button`，与抽屉里其他按钮一致 |

### 检查方法

- 浅色与深色各看一遍：轨道用 `theme().muted`、进度用品牌金黄，两边都要有对比度。
- 把窗口不透明度调到 40%：进度条和徽章跟着变淡，不能有一块是实色。
- 打开系统「减弱动态效果」：按压不再缩放、行不再滑动、撤销条直接消失，其余状态（颜色、选中）不变。
- 打卡一次：对勾按钮应有一次轻微的弹性放大，约 0.5s 回到原位；撤销条出现时上移淡入，撤销后先退场再消失。
- 新建 / 删除一行：其余行应在 240ms 内滑到新位置，而不是瞬间跳一格。
- 下载中断（拔网线）后重试：进度从 0 重新推进，不残留上一轮的宽度。
